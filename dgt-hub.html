Electronic board compatibility

DGT Pegasus

Bluetooth Low EnergyiPad route available through supported app/adapter

Pegasus is designed for online play and connects over Bluetooth LE. iPad browser access is not the same as DGT Chess app access; MaxChess still needs its own compatible bridge before it can read live moves directly.

USB e-Boards & Smart Boards

USB-CDesktop bridge required

Modern DGT tournament boards and Smart Boards use USB-C. A desktop connection bridge is the practical route. Safari on iPad does not support the Web Serial interface needed by a direct USB browser connection.

Bluetooth e-Boards

Bluetooth ClassicAdapter may be required

Older Bluetooth wooden boards need a compatible Bluetooth-to-computer bridge. iPadOS browser restrictions mean a dedicated adapter or companion app may be needed.

Tournament board strings

Multi-boardDGT LiveChess route

Tournament boards can be linked in groups and managed with DGT LiveChess on a computer. A MaxChess tournament bridge must receive the board feeds before MaxChess can display each live game.

DGT clocks: what can connect?

DGT North American

US delay / Fischer bonusStandalone clock

This is a physical game timer, not a computer-connected clock in the documented DGT e-Board clock-cable list. It can be used beside MaxChess with matching time settings, but MaxChess cannot claim to read or control it electronically.

DGT3000

Board clock cableBest DGT clock integration target

DGT documents the DGT3000 as connectable to compatible e-Boards. A board/clock bridge can be used to carry game and clock information where supported. This requires a working MaxChess device driver.

DGT XL / Echo / Pi

Board-linked models

DGT lists these models among clocks that connect with its e-Boards. Exact control and display features differ by model; each needs protocol-level testing before MaxChess can mark it fully supported.

DGT2010 / 2500 / 1500 / 1001 / 1002

Standalone timer family

These are useful physical clocks, but a compatible e-Board cable or computer data interface is not documented for this group. Use them as independent timers unless a model-specific interface is verified.

Important: “DGT clock support” does not mean every DGT clock can be remotely started, paused, or set by a website. MaxChess will only show a connected status after a real device protocol confirms it.

What MaxChess is building toward

  • Read piece movement from compatible DGT boards and convert it into legal MaxChess moves.
  • Show the physical board position and the online board position together.
  • Support takebacks, new-game setup, orientation, and move synchronization.
  • Receive clock information from supported board-and-clock combinations such as a DGT3000 setup.
  • Keep standalone clocks such as the DGT North American clearly identified as manual-use devices unless a verified data interface exists.
  • Provide a tournament route for multiple DGT boards through a computer running DGT LiveChess.

No MaxChess password, DGT account password, or private key should ever be entered into a hardware connection screen.
