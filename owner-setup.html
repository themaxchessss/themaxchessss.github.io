MaxChess contribution setup

Setup guide for the site maintainer and the parent or guardian managing payments.

Who can change the page?

MaxChess is hosted on public GitHub Pages. A static webpage cannot securely check whether a visitor is signed in to the MaxChess account lionsmb36. This page is a public guide, not a private login or password-protected dashboard.

Publishing changes is controlled by GitHub repository permissions. Keep write access to themaxchessss/themaxchessss.github.io limited to the intended GitHub account(s). If the GitHub account used by the owner is not the same identity as lionsmb36, GitHub permissions—not the MaxChess username—determine who can edit.

PayPal setup (parent or guardian)

  1. Your dad creates and verifies a PayPal payment or donation link using an account he manages and is eligible to use.
  2. He checks the recipient name, currency, contribution options, and PayPal's terms and fees.
  3. He gives the site maintainer only the public PayPal URL. Never share a password, sign-in code, API secret, or private account information.
  4. The maintainer adds that URL to the PAYPAL_DONATION_URL setting in support.html, then checks that the button opens the correct official PayPal page.

Current state: The PayPal URL is blank. The public support page therefore shows that contributions are not open yet.
