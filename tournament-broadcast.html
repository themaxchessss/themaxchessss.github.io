Connect DGT electronic boards

MaxChess receives the tournament display from DGT LiveChess Cloud. The boards connect to the tournament computer running DGT LiveChess; this webpage is the viewer and broadcast layout.

1 · Connect the boards

Connect DGT USB, Bluetooth or Smart Boards to a Windows, Mac or Linux tournament computer and confirm they appear in DGT LiveChess.

2 · Publish from LiveChess

In DGT LiveChess, set up the tournament and pairings, start recording the boards, then configure Output → LiveChess Cloud export.

3 · Paste the tournament link

Copy the tournament output/view link generated by DGT LiveChess Cloud and paste it below. The live board feed should appear above if DGT allows embedding that link.

For safety, only HTTPS links on livechesscloud.com are accepted. If the DGT page refuses embedding, use its own viewer link in a browser source or use the PGN preview section below. DGT hardware connection is managed by DGT LiveChess, not by iPad Safari.

PGN backup preview

If you have an exported PGN file, you can load it here as a backup preview. This does not create a live DGT connection.
