Connect a DGT tournament

Paste the tournament viewer link created by DGT LiveChess Cloud. MaxChess will read the tournament, pairing and game feeds and draw its own board view. You do not need to paste a private DGT password.

Preview the broadcast style without real tournament data: Open the MaxChess sample broadcast.

1 · Connect the boardsOn a Windows, Mac or Linux tournament computer, run DGT LiveChess and connect the physical DGT e-Boards.
2 · Publish the gamesIn DGT LiveChess, start recording the selected boards and add the LiveChess Cloud exporter under Output.
3 · Share the viewer linkCopy the tournament URL from LiveChess Cloud and paste it below. A UUID copied from the link also works.
4 · Put it on YouTubeAfter MaxChess connects, copy the OBS link. Add it to OBS as a Browser source, set 1920 × 1080, and place it in your YouTube livestream scene.

MaxChess reads the public JSON feed from LiveChess Cloud. This is a community-observed feed format rather than a published DGT developer API. If DGT changes the feed or blocks browser requests, the connection will show an error instead of pretending to be live.
